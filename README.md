# TrenD

최신 유행에 민감한 10대·20대를 위해 유튜브·틱톡·인스타그램의 인기 콘텐츠를 실시간 TOP 100과 1년 전 오늘 아카이브로 보여주는 반응형 트렌드 차트 프론트엔드입니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
npm run preview
```

## 구현 기능

- 실시간 TOP 100 / 1년 전 오늘 화면 전환
- YouTube, TikTok, Instagram 플랫폼 필터
- 콘텐츠·크리에이터·카테고리 검색
- 20개 단위 더 보기
- 콘텐츠 상세 모달, 저장 및 링크 복사
- 각 플랫폼 검색 결과로 연결되는 외부 링크
- 데스크톱·태블릿·모바일 반응형 UI

## 실제 데이터 연동 시

현재 화면의 순위와 조회 수는 UI 확인용 샘플 데이터입니다. 운영 서비스에서는 각 플랫폼의 공식 API 또는 이용약관을 준수하는 데이터 공급사를 서버에서 연동한 뒤, 10분 단위 스케줄러로 순위를 갱신하는 방식을 권장합니다. 과거 차트는 매일 스냅샷을 데이터베이스에 저장해 날짜별로 조회하면 됩니다.
